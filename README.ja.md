# windowsapp-va-sender v1.1.4

**動作対象：Windows 10 22H2 / Windows 11（x64）**


選択したアプリケーションの映像と、そのプロセスの音声をSRT / RTMPで送信するアプリです。

## 使用例

イベント運営、プレゼンテーション、操作デモ、大会やコミュニティ配信などで、選択したWindowsアプリケーションの映像と音声を受信サーバーへ送信します。

## 使い方

1. ZIPをフォルダごと解凍し、windowsapp-va-sender.exeを起動します。
2. 初回起動時に公式FFmpegを自動取得します（約211 MB）。SHA-256を照合して配置します。
3. アプリケーションを起動し、最小化せずに表示します。REFRESHで一覧を更新し、APPLICATIONから対象ウィンドウを選択します。音声の対象プロセスも自動で対応します。
4. SETTINGで設定を選び、SAVEします。
5. OUTPUTに運営チームの受信サーバーURLを入力し、STARTで送信します。STOPで停止します。
6. TESTは20秒のローカル映像・音声確認です。ffplayで再生し、入力したサーバーには送信しません。

一覧には実行ファイル名・PID・ウィンドウ名を表示します。取り込みたいアプリケーションのウィンドウを選択してください。音声は選択ウィンドウを持つプロセスと、その子プロセスから取得します。同じ実行ファイルを複数起動している場合も、異なるPIDを区別します。

対象ウィンドウ・PIDは設定ファイルへ保存しません。起動時に選択してください。更新時は同じウィンドウ・プロセスの起動インスタンスに限り選択を維持します。アプリケーションを再起動したら更新して選択し直します。送信・TEST中は対象を切り替えられません。

## 音声同期補正

SETTING → AUDIO SYNC (ms)で、映像に対する音声の位置を調整できます。初期値は0、範囲は-2000～+2000msです。

- 音声が映像より約0.2秒遅れている場合、まず **-200ms** を試してください。
- 負の値：先頭の音声を指定時間だけ詰め、音声の時刻を先行させます。
- 正の値：先頭に無音を追加し、音声を遅らせます。
- 発砲やメニュー操作など、映像と音の対応がわかる場面で少しずつ調整し、実際の受信プレイヤーでも確認してください。

これは映像と音声の相対的な位置合わせです。送信PCの直接音と受信音を比較したときの、通信・サーバー・再生バッファによる遅延を解消する機能ではありません。FFmpegの構成はすでに音声入力を先に初期化しており、取得順を入れ替えるだけで200msの音ずれを直せるとは確認していません。

通常設定・CUSTOMの両方に適用し、補正値を保存します。

## 言語

初期表示は英語です。SETTING → LANGUAGEでENG / JPNを選び、SAVEすると反映・保存します。FFmpeg・ffplay・Windowsの生ログは原文のままです。

## 出力設定

| サイズ | 30fps | 60fps |
|---|---:|---:|
| 960x540 | CBR 3 Mbps | CBR 4 Mbps |
| 1280x720 | CBR 4.5 Mbps | CBR 6 Mbps |
| 1920x1080 | CBR 6 Mbps | CBR 8 Mbps |

キーフレーム間隔1秒、Bフレーム0、音声128kbps。初期値はSRT / 1280x720 / 30fps / NVEnc P3 / Opus / 音声補正0msです。

- SRT：MPEG-TS、AACまたはOpus。srt:// のURL。
- RTMP：FLV、AAC固定。rtmp:// または rtmps:// のURL。TESTもFLVです。
- CROP：縦横比を維持して中央をクロップ。
- COMPRESS：16:9へ変形。
- LETTER-BOX：全体を収め、余白を黒で埋める。
- CPU：libx264 / veryfast / zerolatency。
- NVEnc：h264_nvenc / P3 / ll / zerolatency。
- AMD：h264_amf / ultralowlatency / speed。

CUSTOMには -オプション 値 の組を指定します。入力・URL・転送形式・フィルター・TEST時間はアプリが管理します。RTMPの音声はAAC / 128kbps / 48kHz / stereoへ統一します。

## 対応環境

- Windows 10/11 x64 / .NET Framework 4.8。.NET 8 Runtimeの追加インストールは不要です。
- GPUエンコードは対応GPU・ドライバーが必要です。
- FFmpegはBtbN N-124714-g49a77d37be-20260531を使用します。
- 対象ウィンドウは最小化を解除してください。アプリの仕様・Windowsのキャプチャ権限によって取得できない場合があります。
- 同じプロセスが複数ウィンドウの音を出す場合、ウィンドウごとの音声分離はできません。関係のない別プロセスから出る音声を自動で取り込む機能ではありません。
- STOP・終了時は、このアプリが起動した補助プロセスだけを終了します。
- 受信まで含めた0.5秒以内の遅延は保証していません。

## アプリケーション選択の既知の事象

AION2とEndfieldは、.NET FrameworkのProcess.HasExitedがアクセス拒否となり一覧から除外されていました。v1.1.4では一覧・音声取得の起動個体／終了確認にPROCESS_QUERY_LIMITED_INFORMATIONを使用します。確認できた一覧除外の原因を修正したもので、その後、利用者により両ゲームのキャプチャ・TEST・送信の動作確認が取れています。TESTやSTARTの前に最小化を解除してください。
